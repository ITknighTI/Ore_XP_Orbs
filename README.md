# Ore XP Orbs

Ore XP Orbs makes Copper, Iron, and Gold ores drop experience orbs when mined, similar to vanilla ores such as Coal, Diamond, Emerald, and Lapis Lazuli.

The experience is dropped as real XP orbs instead of being added directly to the player's XP bar, allowing it to work naturally with Minecraft mechanics such as Mending.

## Features

- ⛏️ Copper, Iron, and Gold ores reward XP
- 🟢 Real XP orbs drop directly from the mined ore
- 🔧 Fully compatible with Mending
- 💎 Fortune works normally
- ✨ Silk Touch prevents XP from dropping
- 🪨 Supports regular and Deepslate ore variants
- 📦 Available as a Datapack and Fabric version

## XP Rewards

| Ore | XP Reward |

| Copper Ore | 20% chance to drop 1 XP |

| Iron Ore | 1–3 XP |

| Gold Ore | 2–4 XP |

Copper has a lower XP reward due to its abundance and large vein sizes.

For comparison, vanilla Diamond Ore drops **3–7 XP**, Coal Ore drops **0-2 XP**.

## Installation

### Datapack

1. Download the Datapack version.
2. Open your Minecraft world folder.
3. Place the `.zip` file inside:
   `saves/<world>/datapacks/`
4. Load the world or run `/reload`.

### Fabric

1. Install Fabric Loader.
2. Install Fabric API.
3. Place the Fabric version of Ore XP Orbs inside your `mods` folder.
4. Launch Minecraft.

Make sure you're using versions compatible with your Minecraft version.
